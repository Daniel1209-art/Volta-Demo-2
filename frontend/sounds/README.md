# VOLTA — звуковые эффекты

Файлы, которые загружает `../VOLTA4-3D.html` (WAV, 22050 Гц, моно, 16-бит).

| Файл | Событие в игре | Характер |
|---|---|---|
| `lamp_on.wav` | включение лампы (ON / автопилот) | щелчок реле + короткий подъём |
| `lamp_off.wav` | выключение лампы (OFF) | щелчок + спад |
| `bet.wav` | ставка принята | подтверждающий «динь» |
| `tick.wav` | отсчёт до старта (5…4) | короткий тик |
| `tick_hi.wav` | отсчёт 3-2-1 | тик выше тоном |
| `round_start.wav` | старт раунда | энергетический power-up |
| `voltage_loop.wav` | гул напряжения во время раунда (луп) | низкий бас; высота растёт с множителем |
| `cashout.wav` | выигрыш при краше (лампа была OFF) | мажорный перелив-«касса» |
| `crash.wav` | краш — лампа разбивается | электро-зап + звон стекла |

Заметки:

- **Замена звука**: положи свой WAV с тем же именем — игра подхватит его без правок кода. `voltage_loop.wav` должен быть бесшовным лупом.
- **Пересоздать все файлы**: `node _generate.js` (чистый синтез, без зависимостей).
- **file:// фолбэк**: если игра открыта двойным кликом и файлы недоступны для fetch, те же звуки синтезируются на лету — копия DSP из `_generate.js` встроена в HTML (`sndRender`).
- **Громкость / отключение** — кнопка-динамик в шапке игры; настройки хранятся в localStorage (`volta_snd`).
